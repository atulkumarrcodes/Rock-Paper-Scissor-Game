A modern, responsive take on the classic Stone Paper Scissors game. Built entirely without frameworks, this project demonstrates DOM manipulation, event delegation, and CSS animations.

Key Features:

Interactive UI: Clean, dark-themed interface built with CSS Flexbox.

Animated Gameplay: CSS keyframe animations simulate the classic "hand shake" before revealing choices.

Dynamic Scoring: JavaScript logic evaluates win/loss/tie conditions and updates the scoreboard in real-time.

Zero Dependencies: Built entirely with pure HTML, CSS, and JavaScript.
